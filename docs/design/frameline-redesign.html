Version 2: every flow, one click at a time. The website builder has been removed and the first redesign reviewed.

I went back through the first redesign screen by screen, and through every flow in the code, as a photographer and as a guest. The layout was the right direction, but it only showed the front door of each area. It left out the screens people reach after a few clicks, it didn't include the guest side, and it broke some of its own rules. Version 2 fixes that. Open Journeys to click through all 12 flows, and use Coverage to check that every screen in the code has a place.

What was wrong with the first redesign, and the fix

ProblemDetailFix in version 2
Only front doorsIt had 15 screens, but the code has about 70 screens and states: dialogs, wizards, empty states, payments and errors.12 journeys that click through from start to finish, plus a coverage table that maps every screen in the code.
No guest sideGuests are most of the people who ever see the product, and v1 showed one phone.A full guest journey: link, PIN, sign-up, selfie, my photos, download, buy, upload, and the blocked states.
Website in the top barIt took a top-level slot for a feature you don't need yet.Removed. The top bar is Home, Events, Sell photos and More. The studio app moves into More.

Gaps found in the product while tracing flows

Missing No way to refund an order

"Refunded" exists as a status and a ledger filter, but no button issues a refund. Added in the Sell journey as an order action with a confirm step, because it moves money.

Missing "Needs you" had no single place

Access requests, guest uploads awaiting review and expiring events were spread over three pages. Home now collects them.

Done Website builder switched off

It's hidden in the admin, gallery and mobile apps behind one switch (FEATURES.website). Enquiry buttons for guests are hidden too, since there's no inbox. The code and data stay, so it can come back later. Typecheck and 96 API tests pass.

Decide Guest "Enquire" buttons

I hid them with the website. If you want guests to still contact the studio, they could go to a WhatsApp button instead, which needs no inbox.
