Google Drive test

Three checks from docs/GOOGLE_DRIVE_PLAN.md, run with your own Google account before Drive is switched on. Nothing here talks to Frameline’s server, and nothing is saved.

0. Keys

From the Google Cloud project: the OAuth web client id (this page’s address must be one of its JavaScript origins), the Picker API key, and the project number.

1. Does picking a folder let Frameline list what’s inside?

Pick one folder that has photos in it. If Google lists them, the import can turn folders into albums. If not, studios will open the folder in the picker and select the photos.


  


  

    
2. Is Drive’s thumbnail good as a 2048 px web copy?

    
Pick one photo. This asks for its thumbnail at 2048 px, the way imports make web copies.

    
    

  


  

    
3. Can the browser upload straight into Drive?

    
Uploads to events that keep originals in Drive: Frameline’s server opens the upload, the browser sends the bytes. Step A opens it here in the browser (always allowed). Step B checks the real case: run the command, which opens an upload the way the server does (with this page’s Origin), paste the address it prints, and send.
